# Portfolio Design System

A small project built as part of the **Codecademy Frontend Engineer** career path.

## About

This is a design system reference page that documents the core visual styles for a portfolio site. It covers:

- **Colors** — a palette of 10 named colors with hex values
- **Fonts** — type specimens for the two chosen typefaces, Lora and Inter
- **Typography** — heading styles (H1–H5), body text sizes, and link styles
